## v7.7.0 Changes
- **CSV** (`src/output/csv.rs`): testssl-inspired 10-column layout; `fqdn/ip` and `port` split; severity/protocol uppercase; `finding` = title + details; CVE from catalog refs; CWE mapped per finding ID
- **HTML** (`src/output/html.rs`): matching column set — ID, Protocol, Severity, CVSS Score, CVSS Vector, Finding, CVE, CWE; uppercase severity/protocol
- **Table** (`src/output/table.rs`): FQDN/IP and Port split; CVE and CWE columns added; Finding combines title+details; uppercase
- **Text** (`src/output/text.rs`): uppercase severity/protocol; CVE/CWE lines appended per finding when present
- **Shared helpers** in `csv.rs`: `cves_for_finding()` extracts CVE IDs from catalog ref URLs; `cwe_for_finding()` maps finding IDs to CWE numbers
